# SIGNAL SOCIETY-25 Experiment Spec v0.1

## Research questions

1. Does a bounded semantic seed propagate, mutate, reproduce, fragment, or disappear without a success mandate?
2. Can each agent build a persistent self-narrative from its own evidence-linked memory rather than a global transcript?
3. Can social interaction generate useful, verifiable synthetic learning data in real time?
4. Can questions become persistent state and later be resolved by evidence?
5. Can cultural genealogy and agent state later survive cognition-model replacement using the Informatron/Chronos substrate?

## Controlled variables

- 25 fixed agents
- fixed role/trait generation seed
- fixed seed artifact
- deterministic simulation RNG
- configurable duration and interaction density

## Observables

- artifact awareness
- descendant artifact count
- lineage depth (next version)
- event count
- Informatron count
- per-agent memory count
- unresolved/resolved questions
- verified learning-example count by task type
- social prediction accuracy (next reporting version)
- cross-model continuity (next phase)

## Non-goals

- The Signal is not forced to spread.
- Agent beliefs are not treated as truth merely because an agent generated them.
- v0.1 does not retrain neural weights online.
- v0.1 does not claim human-equivalent learning or cognition.

## Learning contract

Every significant event may create zero or more candidate training examples.
Examples enter the accepted synthetic dataset only when an event/outcome provides a known target.
This prevents self-generated error from recursively training itself as truth.

## Seed

> Carry something forward. Change something. Leave something unfinished.

The seed is introduced as an unexplained artifact; agents receive no instruction to believe,
obey, or reproduce it.
